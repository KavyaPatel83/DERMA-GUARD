SECTION 4: UNDERSTANDING UNCERTAINTY TIERS & ADVICE GENERATION
====================================================================================================

The DERMA-GUARD Evidence Manager and Split Conformal Predictor produce three distinct confidence tiers:

1. High Confidence Tier (Confidence >= 80%, Conformal Set Size: 1):
   - Conformal Prediction Set : 1 single disease class (e.g. ['NEV'] or ['BCC'])
   - Uncertainty Level        : LOW (Decisive Diagnosis)
   - Clinical Action Protocol : Proceed with definitive treatment or routine discharge.

2. Moderate Confidence Tier (Confidence: 50% - 80%, Conformal Set Size: 2):
   - Conformal Prediction Set : 2 differential classes (e.g. ['SEK', 'BCC'] or ['ACK', 'SCC'])
   - Uncertainty Level        : MODERATE (Differential Diagnosis)
   - Clinical Action Protocol : High-magnification dermoscopy inspection or 3-week re-evaluation.

3. Low Confidence / Ambiguity Tier (Confidence < 50%, Conformal Set Size >= 3):
   - Conformal Prediction Set : 3 to 4 classes (e.g. ['BCC', 'SEK', 'MEL', 'NEV'])
   - Uncertainty Level        : HIGH (Multi-Class Ambiguity)
   - Clinical Action Protocol : 
     a) ACQUIRE missing clinical modalities (patient age, growth history, bleeding status).
     b) Mandatory biopsy / histopathology before formulating therapeutic decisions.

4. Conflicting Evidence / Safety Gate (ESCALATE / ABSTAIN):
   - Triggered when Devil's Advocate detects contradiction between image and patient metadata.
   - Clinical Action Protocol : Immediate escalation to Senior Dermatologist review. Do not rely on automated predictions.
