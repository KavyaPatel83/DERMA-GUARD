One portal, three roles

Built like a real hospital system

Patients

Analyse lesions, track every result, request a doctor's review, book appointments and chat with the care assistant.

Doctors

A risk-ranked review queue with the photo, patient details, model evidence, retrieved knowledge and similar documented cases.

Administrators

Manage accounts and roles, watch system health and read the audit trail — without access to clinical content.

AI agents & retrieval

Six specialist agents, one auditable trail

Every analysis is handled by cooperating agents. You can open the trace for any case and see exactly who did what.

Intake

Reads free-text descriptions and extracts age, body site, size and symptoms.

Vision-Triage

Runs the seven trained models and fuses them by evidence quality.

Safety

Scans for emergency wording and applies escalation guardrails.

Retrieval (RAG)

Hybrid dense + keyword search over a curated knowledge base and 2,298 documented cases.

Referral

Recommends the right department and urgency window.

Report

Writes source-cited summaries for patients and clinicians.

Pipeline

From raw inputs to an auditable decision

Encode

ResNet50 + attention ViT reads the photo, a residual MLP reads patient metadata, Bio_ClinicalBERT reads the narrative.

Profile evidence

Quality, reliability, utility, consistency and missingness are scored per source and combined into sufficiency.

Fuse adaptively

Evidence-weighted fusion up-weights the trustworthy modality and iteratively refines weights using the diagnosis prior.

Gate & explain

A calibrated conformal set and a 4-level consensus decide: accept, arbitrate, acquire more, or escalate.

What's inside

Built to be explained, not just to be accurate

Seven modality combinations

Any mix of image, metadata and text works — the system automatically routes to the matching model (A–G) and compares them all.

Conformal uncertainty

Instead of one overconfident label you get a prediction set (calibrated on held-out data) that grows when the case is ambiguous.

Evidence sufficiency gate

If the inputs are too poor to decide safely, the system refuses to diagnose and tells you what to add.

Image quality pre-check

Instant feedback on sharpness, lighting, contrast and resolution before any model runs.

Sample case library

One-click real cases from the dataset with hidden ground truth, so you can see right and wrong predictions honestly.

Printable reports & history

Every analysis is stored locally with a shareable one-page report and a searchable case history.
