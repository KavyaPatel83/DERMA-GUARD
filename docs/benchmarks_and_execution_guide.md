## 1. Paper Comparisons & Baseline Alignment

DERMA-GUARD v4.0 is evaluated against both literature state-of-the-art papers and an internal 6-level baseline ladder.

### 1.1 Literature Papers Compared Against

| Paper / Model | Architecture / Method | Target Dataset(s) | Primary Metrics | Key Takeaway / Baseline Role |
|---------------|----------------------|------------------|-----------------|------------------------------|
| **SkinM2Former** (Zhang et al., 2025) | Tri-modal cross-attention transformer fusion | Derm7pt, HAM10000 | Accuracy, AUROC, F1 | **Primary Architectural Baseline (Baseline M)**. Equal-weight fusion across image, text, and metadata. |
| **DermFormer** (Cockayne et al., 2025) | Nested ViTs with entropy weighting | Derm7pt, ISIC | Robustness under missing/corrupted modalities | Competing baseline for DERMA-STRESS corruption evaluation. |
| **PanDerm** (Yan et al., 2025) | 1.5M image foundation model | PAD-UFES-20, Derm7pt | Macro-F1 (0.74), Derm7pt AUC (0.88) | Foundation encoder incorporated as Model 2 in our Vision Specialist Team. |
| **DermLIP** (Xin et al., 2025) | Vision-Language Pretraining on Derm1M | Derm1M, Derm7pt | Zero-shot Accuracy, Derm7pt AUC (0.89) | VLM specialist incorporated as Model 1 in our Vision Specialist Team. |
| **DermFM-Zero** (Yan et al., 2026) | Zero-shot dermatology VLM | 7 benchmarks | 73.2% avg zero-shot accuracy | Reference VLM (*weights private*; replaced by DermLIP-PanDerm per spec constraint). |
| **MetaBlock-SE** (Bouzon et al., 2025) | Attention-based metadata fusion | PAD-UFES-20 | Accuracy, F1 | Reference for missing metadata handling on PAD-UFES-20. |

---

### 1.2 Internal Baseline Ladder (B1–B6)

To prove the incremental value of each component, DERMA-GUARD is compared against 6 internal baselines:

```
[B1: ResNet152 Image-Only] ──► [B2: Swin-Tiny Image-Only] ──► [B3: Late Fusion] 
                                                                    │
[DERMA-GUARD v4.0 (Full)] ◄── [B6: Majority Ensemble] ◄── [B5: PanDerm Fine-tuned] ◄── [B4: Multimodal Concat]
```

1. **B1 (`image_only_resnet152`)**: ResNet152 trained on clinical image only using standard Cross-Entropy.
2. **B2 (`image_only_swin_tiny`)**: Swin-Tiny trained on clinical image only using standard Cross-Entropy.
3. **B3 (`image_dermo_late_fusion`)**: Dual ResNet152 (clinical + dermoscopy) averaging output logits.
4. **B4 (`multimodal_concat`)**: Concatenate embeddings `[z_clinical, z_dermo, z_meta, z_text]` with a linear head.
5. **B5 (`panderm_finetuned`)**: PanDerm encoder + linear head fine-tuned on target datasets.
6. **B6 (`ensemble_majority_vote`)**: Majority voting among B1, B2, and B5 (no dynamic weighting or evidence profiling).

## 2. What We Should Expect (Performance Targets)

Unlike standard classifiers that maximize accuracy at all costs, DERMA-GUARD evaluates **safety under imperfect evidence**.

### 2.1 Expected Metrics & Targets

| Metric | Clean Target | DERMA-STRESS Target | Measurement Method |
|--------|--------------|----------------------|-------------------|
| **Top-1 Diagnostic Accuracy** | $\ge 85.0\%$ | $\ge 75.0\%$ (single failure) | Test split evaluation |
| **Macro-F1 Score** | $\ge 0.80$ | $\ge 0.72$ | Macro-average across classes |
| **Expected Calibration Error (ECE)** | $\le 0.08$ | $\le 0.10$ | 10-bin confidence calibration |
| **Unsafe-Decision Rate** | $\le 2.0\%$ | $\le 5.0\%$ | Forced ACCEPT on incorrect cases |
| **Abstention Rate** | $5\% - 10\%$ | $15\% - 25\%$ | Fraction triggering Level 3 (ACQUIRE) / Level 4 (ESCALATE) |
| **Conflict Detection Precision** | $\ge 85.0\%$ | $\ge 80.0\%$ | Precision on synthetic cross-modal conflict injection |
| **Acquisition Recovery Rate** | $\ge 75.0\%$ | $\ge 70.0\%$ | Fraction of uncertain cases resolved after 1 extra modality |
| **Report Hallucination Rate** | $\le 2.0\%$ | $\le 3.0\%$ | Unsupported claims caught by Stage 2 verification |

## 4. Phase-by-Phase Execution Instructions

### Phase 1: Environment & Dataset Setup

1. Configure environment variables in `.env`:
   ```bash
   cp .env.example .env
   # Edit .env to set WANDB_API_KEY and paths
   ```
2. Verify Ollama with Qwen2.5 is running locally:
   ```bash
   ollama run qwen2.5:7b "Hello"
   ```
3. Run dataset audit (SHA-256 hash checks + perceptual hash collision detection):
   ```bash
   python scripts/dataset_audit.py
   ```
4. Generate patient-level splits and synthetic patient text for PAD-UFES-20:
   ```bash
   python scripts/01_prepare_data.py
   python scripts/02_generate_texts.py
   ```

---

### Phase 2: Baseline Ladder Training (B1–B6)

Train all 6 baseline models sequentially:

```bash
# B1: ResNet152 Image-Only
python scripts/04_train_models.py --config configs/experiment/baseline_ladder/b1_resnet.yaml

# B2: Swin-Tiny Image-Only
python scripts/04_train_models.py --config configs/experiment/baseline_ladder/b2_swin.yaml

# B3: Late Fusion
python scripts/04_train_models.py --config configs/experiment/baseline_ladder/b3_late_fusion.yaml

# B4: Multimodal Concat
python scripts/04_train_models.py --config configs/experiment/baseline_ladder/b4_concat.yaml

# B5: PanDerm Fine-tuned
python scripts/04_train_models.py --config configs/experiment/baseline_ladder/b5_panderm.yaml

# Evaluate Baselines
python scripts/06_evaluate.py --split test --baselines all
```

---

### Phase 3: DERMA-GUARD Full System Training

Train PTIS, Evidence Profiler, Dynamic Fusion, RAG index, and Acquisition Policy:

```bash
# 1. Train PTIS v2 regressor
python scripts/03_train_ptis.py

# 2. Train DiagnosisAdaptiveFusion & Evidence Profiler with W&B tracking
python scripts/train_derma_guard.py --run-wandb --epochs 100 --batch-size 32 --lr 1e-4
```

---

### Phase 4: DERMA-STRESS Benchmarking

Run the 15 corruption conditions across all model variants:

```bash
python scripts/run_stress.py --output-dir outputs/stress
```

Conditions tested:
- **Availability**: Missing clinical image, missing dermoscopy, missing metadata, missing text
- **Technical**: Mild/severe Gaussian blur, mild/severe noise, low brightness, heavy JPEG, occlusion patch
- **Semantic**: Contradictory text, vague text, permuted metadata, dermoscopy image swap, metadata poisoning, text hallucination injection
- **Compound**: Multi-failure combination

---
